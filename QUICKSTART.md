# 🚀 Quick Start Guide

Get up and running with the Optimized TSB Mimic Script in under 2 minutes!

## Installation (30 seconds)

### Method 1: Direct Load
```lua
loadstring(game:HttpGet('https://raw.githubusercontent.com/niclaspoopy123/Mimic-/main/Main'))()
```

### Method 2: Manual
1. Copy the contents of the `Main` file
2. Paste into Roblox executor
3. Execute the script

---

## First Time Setup (1 minute)

### Step 1: Launch the Script
- Execute the script using your preferred method
- Wait for the UI to load (~2-3 seconds)
- You'll see a notification: "⚡ TSB OPTIMIZED MIMIC - Script loaded! Maximum performance enabled."

### Step 2: Select a Target
1. Click **"🎯 Select Target (Click Player)"** button
2. Click on any player in the game
3. Notification will confirm: "Target Selected: [PlayerName]"

### Step 3: Start Mimicking
1. Toggle **"⚡ Start Mimic (Ultra Fast)"** to ON
2. You should now be mimicking the target's movements
3. Your character follows their exact position and rotation

---

## Essential Features (30 seconds)

### Enable Basic Protection
In the **⚔️ Combat** tab:
1. Toggle **"🛡️ Anti-Stun"** ON
2. Toggle **"🛡️ Anti-Ragdoll"** ON
3. Toggle **"🛡️ Anti-Launch"** ON

✅ You're now protected from most combat disables!

### Add Visual Aids
In the **👁️ Visuals** tab:
1. Toggle **"📊 Range Visualizer"** ON
2. A colored circle appears showing your attack range
3. Green = target in range, Red = out of range

## Troubleshooting (Quick Fixes)

### Problem: Script Won't Load
**Fix**: 
1. Check internet connection
2. Verify you're in The Strongest Battlegrounds
3. Try a different executor

### Problem: Can't Select Target
**Fix**:
1. Make sure you clicked the "Select Target" button
2. Click directly on the player's character (not the ground)
3. Target must be a valid player with a character

### Problem: Mimic Not Working
**Fix**:
1. Verify target is selected (check notification)
2. Make sure "Start Mimic" toggle is ON (green)
3. Reset your character and try again

### Problem: Getting Stunned Still
**Fix**:
1. Check that Anti-Stun toggle is ON in Combat tab
2. Wait 1-2 seconds after enabling
3. Some server anti-cheats may block this feature

### Problem: FPS Dropping
**Fix**:
1. Disable Range Visualizer
2. Disable Camera Lock-On
3. Lower Roblox graphics settings
4. Close other programs

## Tips for Best Experience

### ⚡ Performance
- Only enable features you need
- Disable Range Visualizer if FPS drops
- Use Prediction Factor of 0.10-0.15 for best performance

### 🎯 Accuracy
- Keep Prediction enabled
- Adjust Prediction Factor based on distance
- Use Lock-On during direct combat

### 🛡️ Safety
- Enable all Anti-Features in combat
- Use Stop All if script acts weird
- Reset character if stuck

### 🎮 Learning
- Use Mimic + Camera Lock to study players
- Enable Moveset Mimic to see their moves
- Practice in low-stakes situations first
